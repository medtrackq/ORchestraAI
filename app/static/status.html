พร้อมใช้งานจริงหรือยัง

สิ่งที่ควรมีก่อนเริ่มนัดผู้ป่วยจริง · กดลิงก์ทางขวาเพื่อไปหน้าที่แก้ได้

    เรื่องที่ผู้ใช้แจ้ง

    ปัญหา ข้อเสนอแนะ และคำถาม จากปุ่ม "💬 แจ้งปัญหา" ทุกหน้า · ระบบปิด HN เลขบัตร เบอร์โทร และชื่อหลังคำนำหน้าให้ก่อนเก็บ · บันทึกถึงผู้แจ้งจะแสดงให้ผู้แจ้งเห็น

    ข้อผิดพลาดของระบบ

    ระบบบันทึกเองเมื่อเซิร์ฟเวอร์ งานเบื้องหลัง หรือหน้าเว็บของผู้ใช้เกิดข้อผิดพลาด ข้อผิดพลาดเดียวกันนับรวมเป็นแถวเดียว · กด "แก้แล้ว" เมื่อแก้แล้ว ถ้าเกิดอีกจะกลับมาเป็นเรื่องใหม่

    เซิร์ฟเวอร์ งานตั้งเวลา และการสำรองข้อมูล

    Supabase แผนฟรีไม่มีการสำรองข้อมูลอัตโนมัติ · ตั้งให้ระบบสำรองเองทุกคืนได้ (หัวข้อด้านล่าง) หรือดาวน์โหลดไฟล์สำรองเองอย่างน้อยสัปดาห์ละครั้ง และเก็บในที่ปลอดภัยของโรงพยาบาล

    วิธีกู้คืนอยู่ในไฟล์ README.txt ในไฟล์ zip (กู้คืนลงฐานข้อมูลใหม่ที่ว่างเปล่า เช่น โปรเจกต์ Supabase ใหม่)

    สำรองข้อมูลอัตโนมัติทุกคืน (เข้ารหัส เก็บใน Supabase Storage)

    กำลังโหลด…
    ไฟล์ (เข้ารหัส)ขนาด
    วิธีตั้งค่า (ครั้งเดียว ประมาณ 5 นาที) และวิธีกู้คืน
    1. Supabase → Project Settings → API Keys → คัดลอกคีย์ service_role (secret key)
    2. ตั้งรหัสผ่านสำหรับเข้ารหัสไฟล์สำรอง อย่างน้อย 16 ตัวอักษร และเก็บไว้อีกที่หนึ่งด้วย (โปรแกรมจัดการรหัสผ่าน หรือซองปิดผนึกที่ฝ่าย IT) · ถ้ารหัสนี้หาย จะเปิดไฟล์สำรองไม่ได้เลย
    3. Render → บริการนี้ → Environment: เพิ่ม SUPABASE_SERVICE_ROLE_KEY และ BACKUP_ENCRYPTION_KEY แล้วกด Save (อย่าส่งค่าเหล่านี้ทางแชตหรืออีเมล)
    4. เมื่อเซิร์ฟเวอร์เริ่มใหม่ กลับมาหน้านี้แล้วกด สำรองตอนนี้ เพื่อทดสอบ

    กู้คืน: กด “ดาวน์โหลด” ไฟล์ .orcbak ในรายการ แล้วบนเครื่องที่มีโค้ด ORchestraAI ตั้ง BACKUP_ENCRYPTION_KEY และ DATABASE_URL ของฐานข้อมูลใหม่ แล้วรัน python -m app.backup restore ไฟล์.orcbak (หรือ decrypt ไฟล์.orcbak ไฟล์.zip เพื่อได้ไฟล์ zip แบบเดิม)

    ไฟล์ SQL ในฐานข้อมูล

    ระบบดูจากตารางและคอลัมน์ที่แต่ละไฟล์สร้าง ว่าฐานข้อมูลมีครบหรือยัง (ไฟล์อยู่ในโฟลเดอร์ supabase/migrations)

    #เรื่องสถานะ

    การตั้งค่าเซิร์ฟเวอร์

    ตั้งที่ Render → บริการนี้ → Environment แล้วกด Save (เซิร์ฟเวอร์จะเริ่มใหม่เอง) · หน้านี้บอกแค่ว่าตั้งแล้วหรือยัง ไม่แสดงรหัสผ่านหรือคีย์ลับ

    เรื่องชื่อตัวแปรสถานะ
    กำลังโหลด…

    ดาวน์โหลดสำรองข้อมูลทั้งหมด

    ไฟล์นี้มี ข้อมูลทุกอย่างในฐานข้อมูล รวม HN และชื่อผู้ป่วย เก็บไว้ในที่ปลอดภัยของโรงพยาบาลเหมือนเวชระเบียน อย่าส่งทางแชตหรืออีเมล · การดาวน์โหลดถูกบันทึกในบันทึกการเข้าถึงข้อมูลผู้ป่วย (PDPA)

    รัน SQL ที่ยังขาด

    ระบบจะรันไฟล์ต่อไปนี้ตามลำดับ ทีละไฟล์ ถ้าไฟล์ไหนผิดพลาดจะยกเลิกเฉพาะไฟล์นั้นและหยุด ข้อมูลเดิมไม่หาย (ทุกไฟล์รันซ้ำได้)

      ใช้เวลาไม่กี่วินาที ระหว่างนี้ผู้ใช้คนอื่นยังใช้งานได้ตามปกติ
